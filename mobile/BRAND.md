# Tixradar brand assets

The final product name is **Tixradar**.

- `assets/Tixradar.svg` — original supplied master wordmark (green + white), intended for dark surfaces.
- `assets/tixradar-light.svg` — same vector paths with the white wordmark portion converted to app ink for light surfaces.
- `assets/tixradar-wordmark-dark.png` / `tixradar-wordmark-light.png` — raster exports used by React Native for consistent iOS, Android, and web rendering.
- `assets/tixradar-icon.png` — square app icon derived from the exact T glyph in the supplied SVG.
- `assets/tixradar-foreground.png` — transparent Android adaptive-icon foreground.
- `assets/tixradar-splash.png` — supplied wordmark prepared for the native splash screen.

The original SVG is preserved unchanged as the canonical logo source.
